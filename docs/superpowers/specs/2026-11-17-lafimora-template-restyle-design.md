# Lafimora Template Restyle Design

## Intent
Bring the existing Lafimora prototype in line with the supplied editorial cream-and-green template while preserving its image-rich multi-page structure and all current Hausa/English, facility, topic, and chat behaviour.

## Goals
- Apply warm ivory, deep forest green, peach/terracotta accents, serif display headings, rounded outlined cards, and restrained shadows across every page.
- Replace generic remote stock photography with local, reusable imagery depicting Northern Nigerian mothers, children, nutrition, and primary healthcare.
- Keep the current number of image placements and responsive behaviour.

## Non-goals
- No new backend, routes, medical claims, or facility data.
- No structural rewrite or framework migration.

## Approach
Considered: (1) CSS-only recolour, (2) full markup rewrite, and (3) token-led restyle plus local image library. Selected (3): it preserves working behaviour and image density while making the visual system and cultural context cohesive.

## Constraints
- Static HTML, CSS, and JavaScript only.
- Existing accessibility and language switching must remain intact.
- Generated imagery must be local project content with no text, logo, or watermark.
