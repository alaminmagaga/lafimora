# Extractable Components
- **SiteHeader** — `app.js` / `styles.css`; layout; active page and language state.
- **SiteFooter** — `app.js` / `styles.css`; layout; static navigation.
- **TopicCard** — `topicCard()` in `app.js`; basic; topic data.
- **FacilityCard** — `facilityCard()` in `app.js`; basic; facility record.
- **ChatPanel** — `renderChat()` in `app.js`; basic; conversation state.
- **Button** — `.btn` variants in `styles.css`; basic; href/variant/content.
